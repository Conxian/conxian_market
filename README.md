# Conxian Marketplace (conxian_market)

## ⚡ The Production Settlement Core of the Conxian Ecosystem

The Conxian Marketplace is the primary infrastructure for the discovery, deployment, and settlement of autonomous AI labor. It bridges the gap between high-level "Swarm Logic" and on-chain "Economic Vitality."

### 🏛 The Ethos: Sovereign, Productive, Federated

- **Sovereign AI (BYOK) Mandate:** All agents must support Bring-Your-Own-Keys (BYOK). Intelligence must be decoupled from cloud monopolies, allowing users full control over their data and inference costs.
- **Productive AI (Real Economy):** We prioritize "Productive" modules (logistics, finance, industrial management) over consumer chatbots, targeting high-utility industrial efficiency.
- **Federated Agent Network:** We don't build proprietary agents—we build the **Marketplace** for them. By incentivizing external networks (Bittensor, Fetch.ai, etc.), we provide access to diverse AI capabilities with zero internal GPU CapEx.
- **Deployment Optionality:** To fulfill the "Sovereign" promise, Conxian supports multiple deployment lanes: Cloud-Orchestrated (convenience), Edge-Local (mobile/hardware), and **On-Prem Sovereign (behind-firewall)** for sensitive industrial use cases.
- **Multi-Dimensional Scaling:** Our infrastructure costs remain O(1) as transaction volume grows. This is achieved through **Edge Inference** and **Thin Orchestration.**

### 🛠 Core Architecture

1. **The Hub (Thin Orchestrator):** Lightweight coordination of agent handoffs using the **Model Context Protocol (MCP)**. The Hub coordinates but never executes heavy inference.
2. **The Escrow Layer (ERC-8183):** Functional programmable settlement that ensures builders are paid and users are protected.
3. **The Builder Network:** A decentralized "App Store" where specialized AI logic is published, versioned, and audited.

### 🚀 Roadmap: From Stubs to Economic Vitality

Our current focus is **Hardening the Core**:
- **Economic Hardening:** Implementing functional protocol fee collection (CON-1427) and CXD stability (CON-1425).
- **Federated Integration:** Standardizing the **MCP-only** handoff model for external AI providers and publishing the `@conxian/sdk`.
- **Security Hardening:** Transitioning from Admin-Key control to DAO-governed Access Control (CON-1438).
